# AI-powered Document Platform

AI-powered Document Platform is a full-stack application for document management and analysis.

## Project Structure

- `backend/`: API services and core business logic
- `frontend/`: user interface and client-side application

## Highlights

- User login and logout APIs
- Health check endpoint
- Backend service layer with handlers and schemas
- Frontend application for interacting with document workflows

## Getting Started

1. Clone the repository.
2. Set up dependencies for backend and frontend.
3. Configure environment variables.
4. Run backend and frontend services.
