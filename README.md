# AI-powered Document Platform

AI-powered Document Platform is a full-stack project with a Python backend and frontend application.

## Project Structure

- `backend/`: FastAPI services, schemas, handlers, and database integrations.
- `frontend/`: Client-side application for interacting with the platform.

## Features

- Health check API
- User login/logout APIs
- Backend service architecture with modular handlers and services

## Getting Started

### Backend

1. Navigate to `backend/`.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python main.py
   ```

### Frontend

1. Navigate to `frontend/`.
2. Install dependencies and start the frontend app (based on the frontend stack setup).
